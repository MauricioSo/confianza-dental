# Security policy

## Reporting a vulnerability

Please do not open a public issue with credentials, personal data, private URLs, screenshots of admin areas, or exploit details that would make an active vulnerability easier to abuse.

Contact the maintainer through [heymauricio.com](https://heymauricio.com) with:

- a short description of the affected component;
- reproduction steps using synthetic data;
- the affected WordPress and PHP versions;
- the potential impact.

The public package intentionally excludes local environments, test fixtures, development dependencies, private documentation, credentials, and commercial modules.
