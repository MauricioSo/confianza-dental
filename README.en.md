# Confianza Dental

Free and open-source WordPress theme for dental clinics that want to communicate trust, clarity, and professionalism without relying on heavy builders.

Author: Mauricio Soto · [heymauricio.com](https://heymauricio.com)

## Scope of this edition

This folder is the public free distribution of the theme. It contains only the FREE core: homepage, clinic, treatments, professionals, and contact pages; testimonials, FAQ, native contact form, WhatsApp, map, basic SEO, and trust-focused visual components.

Commercial capabilities outside this edition were physically excluded from the package. Promotion modules, embedded booking, advanced statistics, certifications, CRM, advanced analytics, multi-location features, and paid external integrations are not included.

The FREE/PREMIUM boundary and exclusion inventory are documented in `qa/confianza-dental-free-premium-classification-v1.html` and in the project’s public-readiness v2 report.

## Requirements

- WordPress 6.5 or newer
- PHP 7.4 or newer

## Installation

1. Copy the folder into `wp-content/themes/`.
2. Activate it from `Appearance > Themes`.
3. Configure the site from `Appearance > Customize`.
4. Create and publish your treatments, professionals, testimonials, and FAQs.

## Included features

- Customizer controls for identity, contact, homepage, clinic, and reusable components.
- Content types for treatments, professionals, testimonials, and FAQs.
- Native contact form with validation and honeypot protection.
- WhatsApp, phone, email, and social links.
- Sanitized map embed field.
- Responsive templates for archives, single entries, clinic, contact, and 404 pages.
- Block patterns and featured-image support.

## Publication security

- Development dependencies, `node_modules`, `vendor`, E2E tests, fixtures, internal screenshots, and commercial documentation are excluded.
- `.env` files, keys, certificates, databases, dumps, and credentials are excluded.
- Read `SECURITY.md` before opening an issue containing sensitive information.
