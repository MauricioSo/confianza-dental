# Confianza Dental

Tema WordPress gratuito y de código abierto para clínicas dentales que quieren comunicar confianza, claridad y profesionalismo sin depender de builders pesados.

Autor: Mauricio Soto · [heymauricio.com](https://heymauricio.com)

## Alcance de esta edición

Esta carpeta es la distribución pública gratuita del tema. Incluye únicamente el núcleo FREE: portada, páginas de clínica, tratamientos, profesionales y contacto; testimonios, FAQ, formulario nativo, WhatsApp, mapa, SEO básico y componentes visuales de confianza.

Las funciones comerciales que no forman parte de esta edición fueron excluidas físicamente del paquete. No se incluyen módulos de promociones, reservas embebidas, estadísticas avanzadas, certificaciones, CRM, analítica avanzada, multisitio ni integraciones externas de pago.

La frontera FREE/PREMIUM y el inventario de exclusión están documentados en `qa/confianza-dental-free-premium-classification-v1.html` y en el reporte de preparación pública v2 del proyecto principal.

## Requisitos

- WordPress 6.5 o superior
- PHP 7.4 o superior

## Instalación

1. Copia la carpeta en `wp-content/themes/`.
2. Actívala desde `Apariencia > Temas`.
3. Configura el contenido desde `Apariencia > Personalizar`.
4. Crea y publica tus tratamientos, profesionales, testimonios y FAQ.

## Funciones incluidas

- Customizer para identidad, contacto, portada, clínica y componentes.
- Tipos de contenido para tratamientos, profesionales, testimonios y FAQ.
- Formulario de contacto nativo con validación y honeypot.
- Enlaces de WhatsApp, teléfono, email y redes sociales.
- Bloque de mapa sanitizado mediante HTML permitido.
- Plantillas responsive para archivos, fichas individuales, página clínica, contacto y 404.
- Patrones de bloques y soporte de imagen destacada.

## Seguridad de publicación

- No se incluyen dependencias de desarrollo, `node_modules`, `vendor`, pruebas E2E, fixtures, screenshots internos ni documentación comercial.
- No se incluyen archivos `.env`, llaves, certificados, bases de datos, dumps ni credenciales.
- Revisa `SECURITY.md` antes de abrir un issue con información sensible.
